## Ementa

Fundamentos de Interação Humano-Computador. Fundamentos teóricos em IHC. Ergonomia de Software. Prototipação de Interfaces. Avaliação de Interface.

## Objetivos

Fornecer as diretrizes e técnicas de projeto de interface com o usuário; apresentar os conceitos relacionados a preparação e a realização de uma avaliação de usabilidade, utilizando diferentes métodos de avaliação de interface com o usuário.
