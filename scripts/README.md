# Scripts

| Script | Uso |
|---|---|
| [`catalogo.py`](catalogo.py) | Sincroniza pastas e READMEs das disciplinas com o Catálogo de Graduação da UFV (`baixar`, `organizar`, `gerar`). Veja [Atualização da Matriz Curricular](../README.md#atualização-da-matriz-curricular). |

Requisitos: Python 3.9+ e `pdftotext` (pacote `poppler`: `brew install poppler` ou `apt install poppler-utils`).
