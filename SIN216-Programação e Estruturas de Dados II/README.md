## Ementa

Fila. Deque. Pilha. Tabela Hash. Árvore. Árvore Binária. Árvore Balanceada.

## Objetivos

Estudar os diversos mecanismos de organização de dados (estrutura de dados) e saber implementar suas principais operações. Ser capaz de decidir, diante de uma situação real, qual a estrutura de dados mais adequada para a solução de um problema.

## Conteúdo programático

1. **Fila** (8 h)
   - Definição do tipo abstrato Fila
   - Fila estática
   - Fila dinâmica
   - Aplicações
2. **Pilha** (8 h)
   - Definição do tipo abstrato Pilha
   - Fila estática
   - Fila dinâmica
   - Aplicações
3. **Tabela Hash** (8 h)
   - Definição
   - Aplicações
   - Calculando a posição chave (função hashing)
   - Inserção e busca sem colisão
   - Hashing universal
   - Hashing perfeito e imperfeito
   - Tratamento de Colisões
4. **Árvore** (4 h)
   - Definições
   - Aplicações
5. **Árvore Binária** (16 h)
   - Definição do tipo abstrato árvore binária
   - Representações
   - Recursividade
   - Métodos de caminhamento
   - Árvores binárias de pesquisa
6. **Árvore Balanceada** (16 h)
   - Árvore Balanceada
   - Rotações
   - Operações: inserção e remoção
