## Ementa

Linguagem SQL avançada. Indexação em banco de dados. Processamento e otimização de consultas. Processamento de transações e controle de concorrência. Técnicas de banco de dados avançado.

## Objetivos

Introduzir conceitos mais avançados relacionados com Banco de Dados, mostrando para os alunos a teoria e a prática de forma conjunta.
