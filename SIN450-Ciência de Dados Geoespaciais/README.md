## Ementa

Introdução à ciência de dados geoespaciais. Conceitos básicos de linguagens de programação para manipulação de dados geoespaciais. Manipulação de dados geoespaciais. Resolução de problemas utilizando dados espaciais. Visualização de dados geoespaciais.

## Objetivos

Entender os conceitos básicos e a terminologia da ciência de dados geoespaciais; Adquirir dados geoespaciais de diferentes fontes;

Transformar e manipular dados geoespaciais;

Resolver problemas por meio da análise de dados geoespaciais;

Criar visualizações de dados geoespaciais.

## Conteúdo programático

1. **Introdução à ciência de dados espaciais** (8 h)
2. **Conceitos básicos de linguagens de programação para manipulação de dados geoespaciais** (8 h)
3. **Manipulação de dados geoespaciais** (18 h)
4. **Resolução de problemas utilizando dados espaciais** (18 h)
5. **Visualização de dados geoespaciais** (8 h)
