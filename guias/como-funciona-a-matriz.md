A matriz em vigor é a do Catálogo de Graduação UFV 2026. Ela define quais disciplinas são obrigatórias, em que período cada uma é sugerida e o que é preciso ter cursado antes.

## Carga horária e prazos

| | Horas |
|---|---|
| Disciplinas obrigatórias | 2700 h |
| Disciplinas optativas | 360 h |
| **Total** | **3060 h** |

O prazo padrão para concluir o curso é de 4,0 anos, e o máximo é de 6,5 anos. O quadro acima é o do catálogo. Somando as disciplinas obrigatórias listadas período a período, o total dá 2640 h.

O período indica a ordem sugerida, não uma obrigação. O que de fato limita a matrícula são os pré-requisitos.

## Pré-requisitos e correquisitos

- **Pré-requisito:** a disciplina só pode ser cursada depois da aprovação na outra. Exemplo: [SIN215 — Programação e Estruturas de Dados I](<../SIN215-Programação e Estruturas de Dados I/>) exige [SIN111 — Fundamentos de Programação](<../SIN111-Fundamentos de Programação/>).
- **Correquisito**, marcado com `*` no catálogo: pode ser cursado no mesmo semestre. Exemplo: [SIN421 — Interação Humano-Computador](<../SIN421-Interação Humano-Computador/>) tem [SIN221 — Engenharia de Software I](<../SIN221-Engenharia de Software I/>) como correquisito.
- **Carga horária mínima:** [SIN495 — Projeto Integralizador de Extensão](<../SIN495-Projeto Integralizador de Extensão/>) e [ADE327 — Empreendedorismo](<../ADE327-Empreendedorismo/>) exigem 1800 h de disciplinas obrigatórias concluídas.
- **Alternativas:** "MAP 191 ou MAP 195" significa que qualquer uma das duas atende.

## Onde conferir cada disciplina

Cada pasta deste repositório traz a ementa, os objetivos, o conteúdo programático e a bibliografia do programa analítico oficial, além do link para o PDF. Em caso de divergência, vale o PDF publicado pela UFV.
