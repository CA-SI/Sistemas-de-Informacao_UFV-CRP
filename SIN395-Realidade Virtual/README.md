# SIN395 — Realidade Virtual

> **Optativa** · 60 h (4 h teóricas + 0 h práticas por semana) · 4 créditos · Semestres: I e II

| | |
|---|---|
| **Pré-requisitos** | Nenhum |

## Ementa

Introdução à Realidade Virtual. Dispositivos Adequados à Realidade Virtual. Processos de Desenvolvimento de Sistemas de Realidade Virtual. Linguagens. Exemplos de Aplicação. Interação em Ambientes Virtuais.

## Objetivos

Apresentar conceitos relacionados ao tema Realidade Virtual como: dispositivos, processos de desenvolvimento e linguagens de aplicação.

## Conteúdo programático

1. **Introdução à Realidade Virtual** (10 h)
   - Primórdios da RV
   - Caracterização de RV
   - Sistemas de RV
   - Realidade Misturada
   - Realidade Aumentada
   - Virtualidade Aumentada
2. **Dispositivos Adequados à Realidade Virtual** (8 h)
   - Dispositivos de Entrada de Dados
   - Dispositivos de Saída de Dados
3. **Processos de Desenvolvimento de Sistemas de Realidade Virtual** (12 h)
   - Sistemas de Realidade Virtual
   - Desenvolvimento de SRV
   - Processo de Desenvolvimento de SRV
   - Modelagem e Programação de Ambientes Virtuais Interativos
   - Grafo de Cena e Gerenciadores
4. **Linguagens** (12 h)
   - VRML
   - X3D
5. **Exemplos de Aplicação** (8 h)
   - A Realidade Virtual na Educação e Treinamento
   - Realidade Virtual nas Artes
   - A Realidade Virtual na Indústria de Exploração e Produção de Petróleo
   - Aplicações de Ambientes Virtuais Colaborativos
6. **Interação em Ambientes Virtuais** (10 h)
