## Ementa

Sistemas de Apoio Organizacional e Gerencial. Gerenciamento de Sistemas de Informação. Aplicações da Tecnologia de Informação nas empresas. Engenharia de Software para aplicações Web. Novos paradigmas em engenharia de software. Desenvolvimento dirigido a modelos. Padrões de software.

## Objetivos

Apresentar os tipos de sistemas de apoio organizacional, gerencial e de tomada de decisão. Apresentar uma visão geral sobre o desenvolvimento e aplicação de tecnologia da informação. Apresentar as atividades do processo de software para a criação de aplicações Web. Fornecer uma visão geral sobre os diferentes paradigmas em engenharia de software.

## Conteúdo programático

1. **Sistemas de Apoio Organizacional e Gerencial** (6 h)
   - Sistemas de Informação e Organizações
   - Sistemas de Gestão do conhecimento
   - Tecnologias da Informação e Processo Decisório
   - Melhoria da tomada de decisão administrativa
   - O Papel da Inteligência Artificial
2. **Gerenciamento de Sistemas de Informação** (6 h)
   - Conceitos e Definições
   - Fatores críticos do gerenciamento
   - Gerenciamento de Recursos de Dados
   - 1 Data Warehouse
   - Data Mining
3. **Aplicações da Tecnologia de Informação nas empresas** (16 h)
   - Redes de comunicação (rede local, intranet, extranet, internet)
   - Negócios entre empresas (e-business)
   - Comércio eletrônico (e-commerce)
   - Provedores de serviços de aplicações (ASPs)
   - Sistemas integrados de gestão empresarial (ERP)
   - Gerenciamento de relacionamento com cliente (CRM)
   - Gestão da Cadeia de Suprimentos (SCM)
4. **Engenharia de Software para aplicações Web** (8 h)
   - Conceitos e Definições das WebApps
   - Processo de Desenvolvimento para WebApps
   - Modelagem de Aplicações Web
   - Ferramentas CASE aplicáveis
5. **Novos paradigmas em engenharia de software** (12 h)
   - Linhas de Produto de Software
   - Desenvolvimento baseado em Componentes
   - Computação Orientada a Serviços
   - Computação Ubíqua
6. **Desenvolvimento dirigido a modelos** (6 h)
   - Arquitetura Dirigida a Modelos
7. **Padrões de software** (6 h)
   - Visão Geral
   - Histórico
   - Tipos de Padrões de Software
   - Anti-Padrões
