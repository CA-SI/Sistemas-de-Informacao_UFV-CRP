## Ementa

Engenharia de Sistemas. Produto e Processos de Software. Processos de desenvolvimento de software. Requisitos de software. Modelagem de sistema. Projeto e implementação. Verificação e validação de Software. Qualidade do Software. Visão geral sobre gerenciamento de projetos de software. Evolução de Software.

## Objetivos

Fornecer uma visão geral do processo de desenvolvimento de software e qualidade de software: atividades, métodos e ferramentas.
