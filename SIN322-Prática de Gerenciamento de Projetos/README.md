## Ementa

Conceitos de gestão de projetos. Planejamento de projeto. Definição do cronograma e acompanhamento do progresso do projeto. Gerenciamento de pessoal. Gerenciamento de risco. Gerenciamento da qualidade. Gestão de configuração de software.

## Objetivos

Oferecer uma visao geral dos principais conceitos relacionados a uma gestao efetiva de projetos, abordando as áreas de conhecimento dos grupos de processos de um projeto: iniciação; planejamento; execução; monitoramento e controle e; encerramento.

## Conteúdo programático

1. **Conceitos de gestão de projetos** (6 h)
   - Definição de processo de negócio
   - Gerenciamento de projeto e modelos de referência
   - O processo de desenvolvimento de sistemas e o ciclo de vida de sistemas de informação
   - Conceitos e ferramentas para gerenciamento de projeto de sistemas
2. **Planejamento de projeto** (4 h)
   - Objetivos do planejamento de projeto
   - Escopo do software
   - Recursos
   - Estimativa do projeto de software
   - Técnicas de estimativa de tamanho
   - Técnicas de estimativa de esforço e de custo de software
   - O plano de projeto
3. **Definição do cronograma e acompanhamento do progresso do projeto** (4 h)
   - Conceitos básicos
   - Divisão do trabalho e gráfico de atividades
   - Definição de um conjunto de tarefas para o projeto de software
   - Seleção das tarefas de engenharia de software
   - Refinamento das tarefas
   - Definição de uma rede de tarefas
   - Definição do cronograma
     - Gráfico de tempo
     - Acompanhamento de cronograma
   - Ferramentas para acompanhar o progresso
4. **Gerenciamento de pessoal** (4 h)
   - Trabalho em grupo
   - Seleção e manutenção de pessoal
   - Modelo de maturidade de capacitação de pessoal
5. **Gerenciamento de risco** (4 h)
   - Riscos de software
   - Identificação de riscos
   - Previsão de risco
   - Atenuação, monitoramento e administração de risco
   - Atividades de gerenciamento de riscos
6. **Gerenciamento da qualidade** (4 h)
   - Qualidade de produto, de projeto e de processo
   - Garantia e padrões de qualidade
   - Planejamento da qualidade
   - Controle de qualidade
   - Medição e métricas de software
7. **Gestão de configuração de software** (4 h)
   - O Processo de SCM
   - Técnicas de comunicação e apresentação de objetos
   - Técnicas de gerenciamento das mudanças e configuração de sistemas
