## Ementa

Visão geral dos métodos para análise e projeto orientados a objetos. Modelagem com objetos usando a notação UML (Unified Modeling Language). Padrões para atribuição de responsabilidades e padrões de projeto. Desenvolvimento do projeto de um sistema de informação típico.

## Objetivos

Apresentar os métodos para análise e projeto orientados a objetos de forma geral.

## Conteúdo programático

1. **Visão geral dos métodos para análise e projeto orientados a objetos** (10 h)
   - O modelo de orientação a objetos
   - Metodologias orientadas a objetos
   - O processo unificado
2. **Modelagem com objetos usando a notação UML (Unified Modeling Language)** (20 h)
   - Requisitos do sistema: modelo de casos de uso
   - Modelo estático: diagrama de tipos e de classes
   - O modelo comportamental
   - Tipos de objetos
   - Operações
   - Contratos
   - Diagramas de estado
     - Diagrama de Interação
     - Diagramas de comunicação
   - Diagramas de comunicação
     - Diagramas de seqüências
     - Diagramas de implementação
     - Ferramentas de apoio
3. **Padrões para atribuição de responsabilidades e padrões de projeto** (15 h)
4. **Desenvolvimento do projeto de um sistema de informação típico** (15 h)
