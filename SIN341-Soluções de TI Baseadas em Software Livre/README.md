# SIN341 — Soluções de TI Baseadas em Software Livre

> **Optativa** · 60 h (4 h teóricas + 0 h práticas por semana) · 4 créditos · Semestres: I e II

| | |
|---|---|
| **Pré-requisitos** | Nenhum |
| **Programa analítico** | [Catálogo de Graduação UFV 2026 (PDF)](https://catalogo.ufv.br/pdf.php?campus=crp&disciplina=SIN%20341&ano=2026) |

## Ementa

Conceitos sobre software livre. Sistemas operacionais livres. Servidores. Ferramentas e utilitários. Desenvolvimento.

## Objetivos

Apresentar aos alunos conceitos relacionados com os softwares livres e apresentar ferramentas e utilitários aplicados à essa abordagem.

## Conteúdo programático

1. **Conceitos sobre software livre** (10 h)
   - Hardware atual, tendências e inovações tecnológicas
2. **Sistemas operacionais livres** (15 h)
   - Instalação
   - Configuração
   - Comandos básicos: GNU/Linux
   - Interfaces Gráficas: GNOME, KDE
   - Programas Gráficos: GIMP, Dia
   - Pacote Office de auxílio a elaboração de documentos
3. **Servidores** (15 h)
   - Servidores Web: Apache e Tomcat
   - Servidores de Processamento: Beowulf e OpenMosix
   - Servidor DNS, FTP
   - Samba
   - Servidor DHCP, Proxy, LDAP, VPN
4. **Ferramentas e utilitários** (10 h)
   - Áudio e Vídeo: VLC, VOIP
   - Firewall
5. **Desenvolvimento** (10 h)
   - Desenvolvimento Web: PHP
   - IDEs de Desenvolvimento: Eclipse e NetBeans
   - SGBDs: MySQL e PostgreSQL
   - Controle de Versões: CVC e SVN
