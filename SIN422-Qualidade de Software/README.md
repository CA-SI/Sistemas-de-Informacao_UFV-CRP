# SIN422 — Qualidade de Software

> **Optativa** · 60 h (4 h teóricas + 0 h práticas por semana) · 4 créditos · Semestres: I e II

|---|---|

## Ementa

Visão geral de qualidade. Avaliação de qualidade de produto de software. Avaliação e melhoria de qualidade de processo de software. Planejamento para melhoria de processo de software.

## Objetivos

O objetivo da disciplina é introduzir conceitos relacionados a qualidade de processo e de produto de software.

## Conteúdo programático

1. **Visão geral de qualidade** (10 h)
   - Produto de software
   - Processo de Software
   - Qualidade de produto de software
   - Qualidade de processo de software
2. **Avaliação de qualidade de produto de software** (10 h)
   - Norma ISO 9126 para qualidade de produto
3. **Avaliação e melhoria de qualidade de processo de software** (20 h)
   - Melhoria de processo de software
   - Modelos Capability Maturity Model (CMM)
   - Norma 15504 - Software Process Improvement and Capability Determination (SPICE) para avaliação e melhoria de processo de software
   - Norma ISO 9000-3 -"Diretrizes para Aplicação da ISO 9001 ao desenvolvimento, fornecimento e manutenção de software"
4. **Planejamento para melhoria de processo de software** (20 h)
   - Gerenciamento de configuração
   - Garantia de qualidade,
   - Planejamento e acompanhamento de projetos
   - Gerenciamento de requisitos
   - Gerenciamento de sub-contratos
