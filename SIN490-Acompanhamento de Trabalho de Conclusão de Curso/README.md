# SIN490 — Acompanhamento de Trabalho de Conclusão de Curso

> **Optativa** · 60 h (4 h teóricas + 0 h práticas por semana) · 4 créditos · Semestres: I e II

| | |
|---|---|
| **Pré-requisitos** | ([SIN 498*](../Z-Matrizes%20Anteriores/SIN498-Trabalho%20de%20Conclus%C3%A3o%20de%20Curso%20I) ou [SIN 488*](../SIN488-Trabalho%20de%20Conclus%C3%A3o%20de%20Curso%20I)) (`*` = correquisito: pode ser cursada no mesmo semestre) |

## Ementa

Trabalhos acadêmicos. Estruturas dos trabalhos acadêmicos (elementos pré-textuais, textuais e pós-textuais). Consulta à base de dados. Como escrever TCC utilizando Latex. Execução da Pesquisa. Organização dos artigos. Estilos de linguagem para escrita de artigos científicos. Seminários de apresentação de TCC.

## Objetivos

Auxiliar o aluno na construção do seu projeto de trabalho de conclusão de curso.

## Conteúdo programático

1. **Trabalhos acadêmicos** (4 h)
2. **Estruturas dos trabalhos acadêmicos (elementos pré-textuais, textuais e pós-textuais)** (12 h)
3. **Consulta à base de dados** (4 h)
4. **Como escrever TCC utilizando Latex** (8 h)
5. **Execução da Pesquisa** (4 h)
6. **Organização dos artigos** (8 h)
7. **Estilos de linguagem para escrita de artigos científicos** (6 h)
8. **Seminários de apresentação de TCC** (14 h)
