## Ementa

Disciplina com intensa atividade de programação. Os problemas de programação incluem estruturas de dados, ordenação, aritmética, álgebra, combinatória, teoria dos números, backtracking, grafos, programação dinâmica, geometria computacional, dentre outros.

## Objetivos

Aprofundar sobre conceitos e métodos de programação através da resolução de problemas de programação, buscando a preparação dos alunos para a participação de campeonatos de Maratona de Programação.
