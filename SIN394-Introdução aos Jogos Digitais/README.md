## Ementa

Estudo analítico de jogos digitais. Projeto de jogos digitais. Personagens e contexto. Elementos de matemática, física e inteligência artificial para jogos digitais. Introdução à programação de jogos digitais.

## Objetivos

Desenvolver habilidades de projeto e programação no contexto de jogos digitais.

## Conteúdo programático

1. **Estudo analítico de jogos digitais** (6 h)
   - Tecnologia
   - Consoles, TV e cinema digital
   - Engines
2. **Projeto de jogos digitais** (14 h)
   - Concepção
   - Storyboard
   - Trilha sonora
   - Interface
3. **Personagens e contexto** (14 h)
   - Personagem
   - Cenários
   - Animação
4. **Elementos de matemática, física e inteligência artificial para jogos digitais** (16 h)
   - Game tree e Game*
   - Incerteza, lógica nebulosa
   - Animação comportamental
   - Mecânica
   - Simulação física
5. **Introdução à programação de jogos digitais** (10 h)
   - Programação em C/C
   - Programação com game engine
