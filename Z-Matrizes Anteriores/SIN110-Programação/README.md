## Ementa

Conceitos básicos de computação. Algoritmos e tipos de dados. Introdução a Linguagem de Programação. Conceitos Intermediários em Linguagem de Programação. Aplicações.

## Objetivos

Desenvolver noções básicas de programação de computadores, possibilitando aos alunos compreender, modelar e programar soluções de problemas através de uma linguagem de programação.

## Conteúdo programático

1. **Conceitos básicos de computação** (4 h)
   - Noções básicas sobre hardware: diagrama de um sistema de computação envolvendo os periféricos
   - Noções básicas de sistemas operacionais, software básico, linguagens, compilação e representação interna dos dados
   - Aritmética binária
2. **Algoritmos e tipos de dados** (2 h)
   - Conceito de processo e algoritmo
   - Notação de algoritmos
3. **Introdução a Linguagem de Programação** (22 h)
   - Linguagem de programação e transcrição de algoritmos
   - Paradigmas de linguagens de programação
   - Introdução a uma linguagem de programação
   - Depuração e documentação de programas
   - Estruturas básicas da linguagem
   - Introdução ao conceito de variáveis
   - Tipos de dados escalares
     - Variáveis e tipos de dados escalares
     - Construções Básicas: Atribuição, Leitura e Escrita
   - Estruturas de decisão
     - Estruturas de repetição
4. **Conceitos Intermediários em Linguagem de Programação** (28 h)
   - Vetores, Matrizes, Strings (Cadeias de Caracteres) e Registros
   - Modularização de programas e apontadores
   - Procedimentos e funções
   - Passagem de parâmetros
   - Ponteiros
   - Estruturas dinâmicas, conceito de recursão, arquivos e suas aplicações
5. **Aplicações** (4 h)
   - Desenvolvimento de programas para implementar projetos de aplicações
6. **Conceitos básicos de computação** (2 h)
   - Utilização de um ambiente computacional básico: operação de equipamentos, obtenção de uma conta em um sistema em rede, noções iniciais de comandos de um sistema operacional
   - Introdução prática a aplicativos simples, como editores de texto, gerenciadores de recursos e navegadores
   - Execução de procedimentos para a produção de programas em uma linguagem de programação: edição, compilação, verificação de erros, execução de um programa
   - 4 Aritmérica Binária
7. **Algoritmos, Lógica de programação e Linguagem de Programação** (4 h)
   - Tradução de algoritmos simples para programas em uma linguagem de programação
   - Programas utilizando variáveis
8. **Conceitos básicos e intermediários de linguagens de programação** (20 h)
   - Desenvolvimento de programas envolvendo estruturas condicionais
   - Desenvolvimento de programas envolvendo estruturas de repetição
   - Programas com chamadas de funções, passagem de parâmetros por valor e por referência
   - Programas utilizando estruturas de dados homogêneas (arrays)
   - Programas utilizando estruturas de dados heterogêneas (registros)
   - Programas utilizando estruturas dinâmicas, recursividade e arquivos
9. **Aplicações** (4 h)
