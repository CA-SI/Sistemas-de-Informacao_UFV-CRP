## Ementa

Modelos de hiperdocumentos. Modelagem de aplicações hipermídia. Especificação de documentos. Construção de aplicações hipermídia na Web. Estudo de caso.

## Objetivos

Apresentar para os alunos os modelos de hiperdocumentos, os modelos de aplicações hipermídias, as especificações de documentos e a construção de aplicações hipermídias.

## Conteúdo programático

1. **Modelos de hiperdocumentos** (6 h)
2. **Modelagem de aplicações hipermídia** (10 h)
   - Multímidia e Hipermídia
3. **Especificação de documentos** (16 h)
   - Documentos estruturados
   - Estruturas hipertexto
   - Estruturas multimídia
4. **Construção de aplicações hipermídia na Web** (16 h)
   - Infra-estrutura de comunicação
   - Infra-estrutura de servidores
   - Arquiteturas de aplicações
   - Ferramentas para manipulação de hiperdocumentos
   - Aspectos de usabilidade
5. **Estudo de caso** (12 h)
