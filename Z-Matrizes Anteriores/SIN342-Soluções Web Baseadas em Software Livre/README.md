## Ementa

Tecnologia básica da web. Arquitetura da informação na web. Conceitos de intranets. Modelagem de aplicações web. Linguagens para construção de aplicações web.

Pré e co-requisitos

SIN 141

## Objetivos

Apresentar para o aluno as tecnologias, arquiteturas, modelagem e aplicações web.

## Conteúdo programático

1. **Tecnologia básica da web** (8 h)
   - HTTP
   - HTML
   - Serviços na Web (web services), etc
2. **Arquitetura da informação na web** (4 h)
3. **Conceitos de intranets** (2 h)
   - Intranets
4. **Modelagem de aplicações web** (4 h)
   - Notação UML para sistemas baseados na web
   - Outras notações
5. **Linguagens para construção de aplicações web** (12 h)
   - Java
   - PHP
6. **Tecnologia básica da web** (8 h)
7. **Arquitetura da informação na web** (4 h)
8. **Conceitos de intranets** (2 h)
9. **Modelagem de aplicações web** (4 h)
10. **Linguagens para construção de aplicações web (T)Teórica; (P)Prática; (ED)Estudo Dirigido; (Pj)Projeto; Total(To)** (12 h)
