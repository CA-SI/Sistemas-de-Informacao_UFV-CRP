## Ementa

Revisão: vetores, registro, ponteiros e alocação estática/dinâmica de memória. Análise da complexidade de algoritmos. Tipo Abstrato de Dados (TADs). Listas. Fila. Deque. Pilha. Matriz Esparsa. Árvore. Árvore Binária. Árvore Balanceada (AVL).

## Objetivos

Estudar os diversos mecanismos de organização de dados (estrutura de dados) e saber implementar suas principais operações. Ser capaz de decidir, diante de uma situação real, qual a estrutura de dados mais adequada para a solução de um problema.
