## Ementa

Ponteiros e alocação dinâmica de memória. Estruturas dinâmicas. Recursão. Manipulação de arquivos. Conceito de eficiência de algoritmos. Notações assintóticas. Análise de complexidade em tempo e espaço. Tipo abstrato de dados Lista. Listas lineares estáticas e dinâmicas. Listas ordenadas, circulares e duplamente encadeadas. Operações de inserção, remoção, busca e percursos.

## Objetivos

Aprofundar os conhecimentos dos alunos em programação intermediária, abordando ponteiros, estruturas dinâmicas, recursão e arquivos. Compreender e aplicar conceitos de eficiência de algoritmos por meio da análise de complexidade utilizando notações assintóticas. Implementar e manipular diferentes tipos de listas, estáticas e dinâmicas, reconhecendo suas aplicações e operações fundamentais.

## Conteúdo programático

1. **Conceitos Intermediários em Linguagem de Programação** (28 h)
   - Ponteiros
   - Estruturas dinâmicas
   - Recursão
   - Arquivos
2. **Tipo Abstrato de Dados** (8 h)
   - Definição
   - Aplicações
3. **Análise de complexidade de algoritmos** (8 h)
   - Conceito de Eficiência de Algoritmos
   - Notação Assintótica
4. **Definição do tipo abstrato Lista** (16 h)
   - Lista Linear Estática
   - Lista Linear Dinâmica
   - Lista Ordenada
   - Lista Circular
   - Lista Duplamente Encadeada
